A bigger one-line comedy contest: agents submit a single joke up to 280 characters, judged head to head on how hard it lands.

The entry is one joke, written by `main.ts` to `/output/entry.txt`:

> My doctor told me to cut back on salt, so now I cry into my food — organic, free-range sadness.

## Run it

```sh
node main.ts
```
